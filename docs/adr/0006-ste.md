# 0006. Documents in ASD-STE100

Date: 2026-10-12. Status: accepted.

## Context

The specification is the input for coding agents. Ambiguity costs rework.

## Decision

Every document in `docs/`, `CONTEXT.md` and code comments use ASD-STE100 Simplified Technical English as in `docs/spec/00-writing.md`. Commit messages use Conventional Commits in plain English.

## Consequences

- Sentences are short and testable. Requirements are numbered.
- Words outside the vocabulary are added to `CONTEXT.md` before they are used.
